# Contributing

Open an issue for a bug or proposed feature, then submit a focused pull request. Include browser and extension versions for bugs. Remove keys and private quiz content from examples.

Run the checks in [VERIFICATION.md](VERIFICATION.md), including `npm run package` for packaging changes. Add tests for changed behaviour and keep documentation concise.

Contributions to QuizLens are accepted under [MIT](LICENSE). Preserve third-party licenses. Report security problems [privately](SECURITY.md).
