# Security reporting

Email [khoa210611@protonmail.com](mailto:khoa210611@protonmail.com) for a private report. Do not disclose vulnerabilities or credentials in public issues.

Include the affected version, browser, reproduction steps, and expected impact. Remove API keys, service tokens, and personal page content from attachments.

Security fixes target the latest release. Reports are reviewed as maintainer time allows; there is no guaranteed response time or bug bounty. Issues in a model provider should also be reported to that provider.
